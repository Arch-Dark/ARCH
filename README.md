# Trading Journal

Journal de trading professionnel développé avec React + Vite.

## Objectif

Créer une application complète permettant de :

- gérer plusieurs capitaux ;
- définir le risque par trade de chaque capital ;
- enregistrer les trades ;
- calculer automatiquement les lots ;
- calculer automatiquement les TP selon le RR ;
- calculer les pips ;
- suivre les gains et pertes ;
- analyser les performances ;
- comparer les stratégies ;
- analyser les actifs ;
- suivre les performances des capitaux actifs et archivés.
